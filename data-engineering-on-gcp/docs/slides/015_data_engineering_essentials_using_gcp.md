## Course Modules Overview

### 1. Setting Up GCP Environment
- Google Cloud account & free credits  
- GCP CLI setup  
- Create and explore your first project  

---

### 2. Google Cloud Storage  
**Build Scalable, Secure Data Lakes**

- Create & manage buckets  
- Apply IAM roles & lifecycle policies  
- Automate with CLI for efficiency  

---

### 3. BigQuery  
**Scalable Data Analytics**

- Write efficient SQL on large datasets  
- Partitioning & clustering for performance  
- Schema design for analytics/reporting  

---

### 4. Cloud Dataflow  
**Batch & Streaming Pipelines**

- Build real-time & batch pipelines  
- Use **windowing** and **triggering**  
- Transform structured/unstructured data  

---

### 5. Cloud Composer  
**Workflow Orchestration with Apache Airflow**

- Create & schedule DAGs  
- Manage dependencies and retries  
- Monitor, troubleshoot & optimize workflows  

---

### 6. Capstone Project  
**End-to-End Data Pipeline**

- Store raw data in Cloud Storage  
- Process via Cloud Dataflow  
- Load into BigQuery  
- Orchestrate using Cloud Composer
